# devtools — أدوات الاختبار المحلية (ماشي جزء من الموقع)

هاد المجلد **ما كيتحطش فالسيرفر**. غير للاختبار المحلي.

- `server.mjs` — سيرفر محلي كيشغل `api.php` الحقيقي عبر PHP 8.3 (WebAssembly)
  وكيقدم الملفات الثابتة. الاستعمال: `node server.mjs ../public_html/public_html 8080`
- `smoke.mjs` — اختبار آلي: كيقلع التطبيق فـ jsdom، كيدخل، كيحسب عدد السطور
  المرسومة وتكلفة الكتابة بالميلي ثانية.
- `lint.mjs` / `probe.mjs` — فحص صيغة PHP.

التنصيب: `npm install`
