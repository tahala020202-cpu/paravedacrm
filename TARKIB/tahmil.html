🚀 الطريقة — 6 خطوات

  1. نزّل جوج ملفات ديال فوق.
  2. حل File Manager ديال الاستضافة → دخل لمجلد public_html.
  3. الباكاب: كليكي يمين على crm_data.json → Download.
    ضمانة فقط. ما غاديش نمسوه.
  4. إلا لقيتي journal.log → امسحو.
    هادا وحدو كيخلي الـCRM أسرع. آمن 100%.
  5. زر Upload ⬆️ → صيفط index.html → اختار Overwrite.
    عاود نفس الشي مع api.php.
  6. حل الـCRM ديالك ودوس Ctrl + Shift + R.
🎉 سالينا. الكتابة خاصها تولي فورية.
